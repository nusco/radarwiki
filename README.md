# RadarWiki

A self-study wiki to learn software things.

RadarWiki is based on the [Thoughtworks Technology Radar](https://www.thoughtworks.com/radar). Each wiki page covers a radar blip. Each is a self-study plan that can be completed in minutes to a few hours.

In RadarWiki, everyone does what they do best: humans produce the content, agents curate the pages. The result is a [collection](pages) of [short courses](`pages/Context engineering.md`) that feel humane, not slop.

RadarWiki is minimalistic: a `SKILL.md` and a folder of Markdown files. If you like, you can use Obsidian as a GUI.

I'm generating new pages as I develop the skill. If you want a page on whatever blip you care about, launch your favorite agent in the root and ask it to generate it. Then start learning.
