# RadarWiki

A personal wiki of self-study plans for Thoughtworks Technology Radar blips. Maintained by agents, generated by humans.

## Principles

1. **Everyone does what they do best.** AI agents curate and maintain the plans, people generate the content.
2. **Radar first.** Every plan starts from a blip.
3. **Minimalistic.** The system is a Claude Code skill and a folder of Markdown files, which I read in Obsidian.
