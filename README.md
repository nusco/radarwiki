# RadarWiki

A self-study wiki to learn software things.

Each page is a quick learning plan for one technology topic. The topics come from the [Thoughtworks Technology Radar](https://www.thoughtworks.com/radar).

## The Core Idea

The idea of RadarWiki is that everyone does what they do best:

- **humans** decide what to learn and produce the content;
- **agents** assemble the content to create the learning plan.

The result is a [collection](pages) of [short courses](pages/Context%20engineering.md) that feel humane, not slop.

## Structure

RadarWiki is minimalistic: a `SKILL.md`, two files in the `templates` folder and a folder of Markdown files. If you like, you can use Obsidian as a GUI.

The [template](templates/template.md) describes what a page looks like. The [learning plan guide](templates/Learning%20plan.md) describes how to fill it in, and holds the learning preferences, such as the default length and pace of the plans. Edit them to make the wiki your own. Existing pages change only when you ask the agent to update them.

## Current Status

I'm generating new pages as I develop the skill. If you want a page on whatever blip you care about, launch your favorite agent in the root and ask it to generate it. Then start learning.

The wiki is currently up to date with volume 35 of the Radar (November 2026).
