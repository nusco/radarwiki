# Professor Wiki

A wiki of self-study plans to learn anything. Maintained by agents, generated by humans.

## Principles

1. **Everyone does what they do best.** AI agents curate and maintain the plans, people generate the content.
2. **Agnostic.** I use Claude Code and Obsidian. You bring your own agent, harness, and interface.
3. **Minimalistic.** The whole system is one installable skill folder.
