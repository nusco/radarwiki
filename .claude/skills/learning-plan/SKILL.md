# Learning plan

Create a self-study plan for: $ARGUMENTS

## Standing rules

- Open the conversation with "IT DEPENDS".
- Answer in chat unless the user asks for a document or file.

## Steps

1. **Pin down the inputs.** Get the topic and time budget from the arguments. If the budget is missing, assume a weekend. If the learner's background is unclear, state your assumption in one line instead of asking.
2. **Split the time into 2–4 layers**, from fundamentals to applied use. Each layer must leave the learner with something usable, so they can stop after any layer.
3. **For each layer, give:**
   - a heading with the time slot and estimated hours
   - a one-line **Goal**
   - 2–4 **Read** / **Watch** resources, each with a link and a short reason it was picked
   - one hands-on **Do** exercise, with later exercises building on earlier ones
4. **Curate resources carefully:**
   - Prefer official docs, well-known conference talks, and established authors.
   - Use only resources you are confident exist. Verify any you are unsure of with a web search.
   - Give video lengths when you know them.
5. **Close with a short "If you have extra time" note** and, if relevant, how to adapt the plan for a beginner.

Keep the whole plan scannable: about one screen per layer at most.
