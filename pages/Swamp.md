## Current state (late 2026)

When a coding agent does an operational task directly, like rotating a key or fixing a pipeline, it may do it differently every time, and leave little record. Swamp, which replaces System Initiative (on the Radar in 2025), has the agent write the automation instead: typed models of external systems and YAML workflows, kept in Git, with each run's output stored as versioned data. The blip is new in November 2026. Swamp is young and moves fast, almost every command needs a swamp-club.com account, and work use needs a paid subscription, so the Radar suggests trying it on low-risk internal automation first.

## Level 1 — What it is (~10 min)

Have agents write repeatable, versioned automation for operational tasks, instead of doing the tasks by hand.

- [ ] **~10 min** · Read: [The Radar blip](https://www.thoughtworks.com/radar/tools/swamp) (~2 min) — note what Swamp adds over "write and commit a script": typed interfaces, run history and reusable modules. Check the license terms too.

## Level 2 — Try it (~25 min)

- [ ] **~25 min** · **Do:** Follow [Install swamp](https://swamp-club.com/manual/how-to/install-swamp) (Swamp manual, ~5 min), then ask your coding agent to automate one small, harmless operational task with it, such as checking that a list of URLs responds. Run the workflow twice, and look at the stored results. Compare with asking the agent to just do the task.
