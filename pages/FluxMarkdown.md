## Current state (late 2026)

With coding agents writing plans, specs and notes in Markdown, developers read a lot more Markdown than before, often outside an editor. FluxMarkdown is a macOS QuickLook plugin that renders Markdown in Finder's preview, including diagrams (Mermaid, Graphviz) and math. It's open source (GPL-3.0, with a commercial license) and mostly maintained by one developer. By default it sends anonymous usage statistics, which you can turn off in its settings.

## Level 1 — What it is (~5 min)

Preview rendered Markdown, with diagrams and math, by pressing Space in Finder.

## Level 2 — Try it (~10 min)

- [ ] **~10 min** · **Do:** Install it from the [README](https://github.com/xykong/flux-markdown) (`brew install --cask xykong/tap/flux-markdown`), turn off usage statistics in its settings if you prefer, and preview a Markdown file with a Mermaid diagram, such as a plan an agent wrote. If the preview doesn't change, see the README's troubleshooting section.
